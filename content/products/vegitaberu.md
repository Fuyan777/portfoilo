## Vegitaberu とは

「Vegitaberu(ベジタベル)」は、**野菜を食べた量をワンタップで記録できるiOSアプリ**です。「健康のために野菜を食べよう」と思っても、毎日の摂取量を細かく入力するのは続かない。だったら、**できる限り操作を減らして、ただ"食べた"を積み上げるだけ**にしたい。そんな発想から生まれました。

「AIといっしょ アプリ100個チャレンジ」の **1本目**として制作したアプリです。

## こだわったポイント

### 1. 写真も詳細入力もいらない

多くの食事管理アプリは、写真を撮ったり、品目を細かく選んだり、グラム数を入れたりと入力ステップが多すぎて続きません。Vegitaberuでは、**「食べた」という事実を記録することだけ**にフォーカスしました。アイコンをタップする数秒で1日分の記録が終わります。

### 2. 1日の合計をひと目で

その日に食べた野菜の合計量がトップ画面で常に見えるようにしました。**目標(例: 1日350g)に対して足りているか・足りていないか**が一瞬で分かるUIに仕上げています。

### 3. 続けやすい設計

野菜摂取は習慣の問題なので、**毎日アプリを開きたくなる仕掛け**が必要です。連続記録の表示や、軽快なアニメーションで「もう1回タップしたくなる」体験を意識しました。

## 開発プロセス

このアプリは、企画→設計→デザイン→コーディング→リリースまで、すべて **AIと一緒に** 進めました。

| 工程 | 使用ツール |
| --- | --- |
| 企画・仕様決め | ChatGPT |
| デザイン | Figma + ChatGPT |
| コーディング | Claude Code |
| アイコン作成 | ChatGPT (Gemini Nano banana) |

合計の制作時間は **6〜7時間ほど**。AIが叩き台を作ってくれるおかげで、1日で形になるスピード感が新鮮でした。

## 振り返り

Vegitaberuは「アプリ100個チャレンジ」の最初のアプリとして、**自分のワークフロー自体をAIで再構築する**良い練習になりました。

- AI が初期実装を一気に作ってくれるので、人間は **UIの細部とユーザー体験** に集中できる
- 「シンプルで使えるもの」だけに絞ると、迷いなく1日でリリースまで持っていける
- 自分が毎日使いたいと思えるテーマだと、開発モチベーションが続く

シンプルな野菜記録アプリですが、**毎日タップする楽しさ**を大切に作りました。健康習慣を始めたい方、ぜひ App Store からダウンロードしてみてください。
